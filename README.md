# ⚡ Electrical Shop — E-Commerce Website

**A front-end e-commerce website for browsing and purchasing electrical appliances**, modeled after real-world retail platforms like Crompton and Panasonic.

---

## 📖 About the Project

This project simulates an online electrical appliances store, letting users browse product catalogs with detailed listings — similar to how established brands like Crompton and Panasonic present their products online. It focuses on clean product presentation and a smooth browsing experience.

---

## ✨ Key Features

- 🛍️ **Product Catalog** — organized listings of electrical appliances with images, descriptions, and pricing
- 📋 **Detailed Product Pages** — specifications and details styled after real brand websites (Crompton, Panasonic)
- 🎨 **Responsive Product Grid Layout** — clean, retail-style UI built with HTML/CSS
- ⚙️ **Interactive Elements** — JavaScript-powered interactions (e.g. product selection, dynamic UI behavior)
- 📱 **Browser-Friendly Design** — works across common screen sizes

---

## 🛠️ Tech Stack

| Layer | Technology |
|---|---|
| Structure | HTML |
| Styling | CSS |
| Interactivity | JavaScript |

---

## 🚀 Getting Started

1. Clone the repository
   ```bash
   git clone https://github.com/janani-pb/electrical-shop-ecommerce.git
   ```
2. Open `index.html` directly in your browser, or
3. Serve locally using any static server:
   ```bash
   npx serve .
   ```
